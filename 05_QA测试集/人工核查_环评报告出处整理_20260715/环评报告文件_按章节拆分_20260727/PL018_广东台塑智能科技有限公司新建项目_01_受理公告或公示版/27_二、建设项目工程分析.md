油性油墨、稀释剂不可替代说明：
本项目油性油墨用于塑料表面印刷，塑料印刷的承印物是塑料薄膜和塑料制品，其分子
结构中含有极性物质，化学稳定性好，能耐大多数酸、碱的腐蚀。在常温下不溶于一般的溶
剂，而且在生产过程中加进抗氧剂。由于塑料承印物与油墨的亲和力差，印刷后油墨也不易
干燥。同时，塑料承印物不具备纸张表面的多孔性，不能吸收油墨连结料。
不同种类低 VOCs 油墨分析
辐射固化油墨：目前应用较普遍的是 UV 油墨，UV-LED 固化是当前较先进的 UV 固化
方式，可以减少臭氧的产生。用辐射固化油墨替代溶剂型油墨可减少 VOCs 产生量 80%以上。
UV 油墨适用于平版、柔版、丝网及凹版印刷，应用于标签、票证、纸包装、金属等的印刷。
妨碍 UV 油墨在塑料材料印刷中的推广主要原因有以下几点：
1、油墨附着力差
塑料材质通常具有较低的表面能，直接印刷时油墨与承印物之间的附着力不足。
2、UV 固化设备有待优化改造
使用 UV 油墨的印刷工序对 UV 固化设备要求较高，需要确保均匀充足的固化能量，否
则可能导致固化不充分，影响印刷质量，如墨层脆化、剥离、附着力下降等。

3、UV 油墨与塑料基材相性不合
不同类型的塑料材质对 UV 油墨的反应可能存在差异，部分塑料材料可能对 UV 油墨的
化学成分有不良反应，或者油墨不能很好地渗入塑料表面，导致印刷质量和耐用性降低。
水/醇性油墨：主要由水溶性连接料、颜料、水、辅助有机溶剂以及助剂组成。辅助有机
溶剂一般分为醇类和醚类。水醇性油墨 VOCs 含量小于 30～50%，用水醇性油墨替代溶剂型
油墨可减少 VOCs 产生量 30～80%。水醇性油墨可应用于塑料表印、轻印刷加工（两种颜色
以内）的购物袋、快递袋及纸包装印刷工艺，使用时通过改浅版或改造烘箱更有利于油墨的
应用。
由于目前印刷使用油墨中含有芳香烃类、酯类、酮类、醚类等有机溶剂，这些溶剂大都
具有毒性和挥发性，印刷排放的废气是印刷行业一个很大的污染源。尽管水性油墨作为溶剂
型油墨的替代产品，已经受到了人们的关注，并寄予了很高的期望，但是油墨的水性进程依
然是缓慢的，妨碍油墨水性化的主要原因有以下几点。
1、印刷质量不佳
目前水性油墨对塑料的黏附性和耐擦性不强，印后的图案附着力不强，耐晒、耐摩擦牢
度不高，易出现散影现象，鲜艳度较低，产品质量影响比较大，印刷效果不如溶剂型油墨。
2、干燥性不好
水性油墨干燥性不好，导致印刷时印速低，增加了能耗和成本，需要对原有的干燥设备
进行改造，或者使用适合水性油墨的专用印刷机。
3、必须改造印版
为了改善水性油墨的干燥性，强化印刷效果，必须改造印版，实现浅版化。目前水性油
墨尚处于研制开发中，虽然时有报道称研制开发成功，但仅仅停留在实验室水平，离实现产
业化还需要一个过程。
4、生产效率有待提高
正常情况下，而水性墨生产速率较低，对生产效率影响比较严重。
综上，本项目使用的油性油墨暂无低挥发性物质可替代。
本项目印刷工序需使用稀释剂对油性油墨进行调配，另外，需使用稀释剂擦洗印刷机和
印版上蘸上的油墨，由于本项目使用的油性油墨为高挥发性物料，根据相似相溶原则，低挥
发性物料与油性油墨的亲和力差，使用低挥发性物料调配的油墨无法达到生产要求，使用低
挥发性物料也无法将印刷机和印版上蘸上的油墨擦洗干净，因此，本项目使用的稀释剂暂无
低挥发性物质可替代。
本项目有机废气经集气罩收集后通过活性炭吸附废气处理设施进行处理，处理达标后通
过排气筒 G1（24m）引至楼顶排放，保证有机废气达标排放。
