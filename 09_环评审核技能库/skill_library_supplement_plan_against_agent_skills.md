# 环评审核技能库补充方案：对照 Agent Skills 综述

## 1. 当前技能库定位

当前 `09_环评审核技能库` 已经形成 15 个单项审核技能和 1 个总审核汇总技能，覆盖国民经济行业类别、环保投资、三线一单、建设内容、环境质量、排放标准、产污系数、源强核算、废气收集、设计风量、收集效率、活性炭、危废识别和 VOCs 总量控制等内容。

对照 Agent Skills 综述，现有技能库已经具备“技能表示”的雏形，即每个技能都有 `SKILL.md`、`config.yaml` 和 `output_example.json`。但如果要让论文内容更扎实，还需要补齐“技能获取、技能检索、技能执行评价、技能演化治理”四个环节。

本课题不需要把技能库做成复杂 Agent 系统。更合适的定位是：将地方塑胶行业环评技术审查中的标准依据、专家经验和样本链证据整理为可复用的审核技能，并用大模型辅助调用、证据定位、问题识别和评分评价。

## 2. 对照 Agent Skills 的补充框架

| Agent Skills 生命周期 | 论文中可对应的研究内容 | 当前已有基础 | 需要补充的内容 |
|---|---|---|---|
| Skill representation 技能表示 | 审核技能如何被结构化表达 | 15 个 `SKILL.md`、`config.yaml`、统一输出 schema | 增加统一元数据字段、触发条件、适用边界、依赖标准、样本链来源 |
| Skill acquisition 技能获取 | 技能从哪里来 | Dify 工作流、塑胶指南、标准库、真实样本链 | 标注每个技能来自哪些标准条目、专家修改意见和样本链案例 |
| Skill retrieval and selection 技能检索与选择 | 不同审核任务如何选择技能 | `skill_registry.yaml` | 建立“10 个原始审核问题-技能-标准-样本链证据”的路由表 |
| Skill execution 技能执行 | 技能如何完成审核判断 | 每个技能已有执行步骤和 JSON 输出 | 增加机器可读核查清单、证据最低要求、失败条件、人工复核触发条件 |
| Skill evaluation 技能评价 | 如何评价技能是否有用 | 已有大模型辅助评分体系试点 | 增加技能级测试样本、专家意见命中率、证据定位准确率等指标 |
| Skill evolution and governance 技能演化治理 | 技能如何更新和校准 | 暂未系统化 | 增加版本记录、人工复核状态、专家校准状态、适用范围变更记录 |

## 3. 建议优先补充的 7 类内容

### 3.1 补充技能元数据

现有 `config.yaml` 已有关键词、字段和来源工作流，但还缺少能支撑论文方法描述的统一元数据。

建议每个技能增加以下字段：

```yaml
skill_type: evidence_check | calculation_check | standard_applicability | expert_experience_check
trigger_conditions:
  - 触发该技能的报告字段或项目情景
not_applicable_conditions:
  - 不适用情景
required_evidence:
  - 必须出现的报告证据
dependent_standard_ids:
  - 对应标准依据库条目编号
sample_chain_cases:
  - 已绑定的真实样本链项目编号
expert_issue_cases:
  - 已绑定的专家修改意见编号
review_status: draft | candidate | human_checked | expert_checked
version_note: 本版本变化说明
```

论文可写点：说明本研究不是简单 prompt，而是将审核任务封装为带有适用条件、证据要求、标准依赖和复核状态的领域技能。

### 3.2 建立“原始审核问题-技能”路由表

你现在有 10 个原始审核母题，但技能库是 15 个技能。建议建立一个路由表，说明每道母题需要调用哪些技能。

示例：

| 原始审核问题 | 主技能 | 辅助技能 | 需要的证据 |
|---|---|---|---|
| 样本筛选与国民经济行业分类 | 01_国民经济行业类别审核 | 04_建设内容完整性审核 | 产品、原辅材料、工艺、行业代码 |
| 环保投资核算 | 02_环评投资核算审核 | 99_总审核汇总 | 总投资、环保投资、环保工程表 |
| VOCs 排放量与治理措施一致性 | 09_源强定量核算审核、15_VOCs总量控制审核 | 10、11、12、13 | VOCs 产生量、收集效率、处理效率、排气筒参数、总量指标 |

论文可写点：从“问题集”到“技能调用”的映射，是技能库区别于普通知识库的重要内容。

### 3.3 绑定标准依据库条目

目前技能里会提到法规库或标准库，但还需要明确“哪个技能依赖哪些标准条目”。

建议增加一个文件：

`skill_standard_dependency_matrix.csv`

字段建议：

```text
skill_id,skill_name,standard_id,standard_name,clause_or_topic,dependency_type,notes
```

依赖类型可分为：

- `mandatory`：没有该标准无法判断；
- `reference`：作为参考经验；
- `boundary`：用于判断适用/不适用边界；
- `calculation`：用于公式、限值或参数核算。

论文可写点：说明标准依据库与审核技能库不是并列堆放，而是通过依赖矩阵连接。

### 3.4 绑定真实样本链和专家意见

全海世家样本链已经有专家评分表和 7 条完善意见，建议把它作为第一个技能校准样本。

建议增加一个文件：

`skill_expert_issue_mapping.csv`

字段建议：

```text
case_id,project_name,expert_issue,matched_skill_id,matched_original_question,evidence_needed,expected_model_behavior,manual_review_status
```

全海世家的 7 条专家意见可绑定到：

| 专家意见 | 对应技能 |
|---|---|
| VOCs 初始排放速率是否大于 2 kg/h | 07、09、15 |
| 危废暂存方式和固废区域面积 | 14 |
| 消耗量合计和物料平衡表 | 04、08、09 |
| 主要生产设施参数 | 04、09 |
| 绿点剩余处理能力 | 13、15 |
| 排气筒风量与内径一致性 | 10、11 |
| 图件比例尺 | 04、99 |

论文可写点：技能不是凭空设定，而是从真实专家意见中反推得到的审核步骤和评价要求。

### 3.5 增加塑胶行业场景技能

现有 15 个技能偏通用审查环节。结合你的研究边界，建议补充 5 个更能体现“佛山市塑胶行业”特色的场景技能。

优先级最高：

1. `16_涉VOCs物料识别审核`
   - 核查胶水、油墨、清洗剂、溶剂、涂料、复合胶等是否识别为 VOCs 相关物料。
   - 重点证据：原辅材料表、MSDS、VOCs 含量、年用量、最大储存量。

2. `17_涂胶复合熟化工艺识别审核`
   - 判断项目是否涉及涂胶、复合、熟化、烘干等塑胶指南重点场景。
   - 重点证据：工艺流程图、产污节点、设备清单、废气收集方式。

3. `18_物料平衡与VOCs闭合性审核`
   - 核查原辅材料消耗量、VOCs 含量、产生量、收集量、处理量、排放量是否能闭合。
   - 重点证据：物料平衡表、源强核算表、总量控制表。

4. `19_依托治理设施能力审核`
   - 核查依托现有治理设施时，剩余处理能力是否足够。
   - 重点证据：现有设施处理能力、已接入项目负荷、本项目新增负荷。

5. `20_修改意见闭环核查`
   - 核查专家修改意见是否在报批稿或终稿中得到回应。
   - 重点证据：评审意见、公示版、报批稿、批复。

论文可写点：这些技能能体现地方塑胶行业审查的领域性，不只是通用环评格式审查。

### 3.6 增加技能级评价指标

结合专家评分表，不建议直接让模型按专家表打报告总分。更稳妥的是建立模型辅助评价指标。

建议指标：

| 指标 | 含义 |
|---|---|
| 证据定位准确性 | 是否找到正确章节、表格、页码或原文片段 |
| 标准适用准确性 | 是否调用正确标准依据或地方指南 |
| 问题识别准确性 | 是否命中真实专家修改意见或人工标注问题 |
| 推理一致性 | 结论是否由证据和标准推出 |
| 修改建议可操作性 | 是否能形成具体修改动作 |
| 风险边界表达 | 是否说明证据不足和需人工复核内容 |

论文可写点：从“模型回答好不好”转化为“技能调用后在证据、标准、问题识别和复核性上的表现”。

### 3.7 增加版本治理和人工复核记录

建议增加：

```text
skill_change_log.md
skill_review_status.csv
deprecated_skills.md
```

`skill_review_status.csv` 字段建议：

```text
skill_id,skill_name,current_version,data_source,human_checked,expert_checked,known_limitations,next_update
```

论文可写点：说明技能库是可维护、可更新的过程性知识库，后续可随着标准变化和专家意见增加而演化。

## 4. 建议按优先级执行

### 第一优先级：让论文方法闭环成立

1. 建立 `10个原始审核问题-技能路由表`。
2. 建立 `技能-标准依据依赖矩阵`。
3. 用全海世家样本链绑定 7 条专家意见和对应技能。
4. 增加技能级评价指标。

完成后，论文可以写清楚：

问题如何拆分为技能，技能如何调用标准依据，技能如何绑定真实样本链，模型输出如何评价。

### 第二优先级：突出塑胶行业特色

1. 增加 `涉VOCs物料识别审核`。
2. 增加 `涂胶复合熟化工艺识别审核`。
3. 增加 `物料平衡与VOCs闭合性审核`。
4. 增加 `依托治理设施能力审核`。
5. 增加 `修改意见闭环核查`。

完成后，论文可以避免变成“通用环评审核工具”，而能突出“佛山市塑胶行业”。

### 第三优先级：支撑后续实验

1. 每个核心技能至少绑定 1 个真实样本链案例。
2. 每个核心技能至少形成 3 道人工复核任务。
3. 对 A/B/C/D 知识条件进行对照：
   - A：仅大模型；
   - B：大模型 + 标准依据库；
   - C：大模型 + 审核技能库；
   - D：大模型 + 标准依据库 + 审核技能库 + 样本链证据。

完成后，论文可以写实验设计和阶段性评价。

## 6. 中期汇报可用表述

可表述为：

本研究借鉴 Agent Skills 关于过程性知识外部化、模块化封装、按需调用和持续治理的思想，将地方塑胶行业环评技术审查任务拆解为若干可复用审核技能。每个技能包含适用边界、证据要求、标准依据、判断规则、输出结构和人工复核条件。与传统知识库只回答“依据是什么”不同，审核技能库进一步回答“如何审、取哪些证据、如何形成可复核意见”。后续将通过真实样本链和专家修改意见，对技能库进行人工校准和评价。

不建议表述为：

- 技能库已经能够自动完成环评审批。
- 技能库已经完全替代专家经验。
- 大模型已经证明可以独立判断环评报告质量。
