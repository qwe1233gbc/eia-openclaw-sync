# 需要补充的参考资料

本包在没有外部资料时也能完成报告内部审核，但以下问题若要形成完整专业结论，需要提供正式资料。

## 01 行业分类

当前包已保留原有分类注释Excel和检索脚本。执行前需确认该版本与报告审核时点一致。

## 05 环境质量

按题提供：

- 官方生态环境状况公报；
- 发布页面或正式附件；
- 大气污染物数据表；
- 河流、断面和水质类别表；
- 报告编制或受理日期。

## 07 排放标准

### 废水

- 企业排放或接管标准；
- 污水处理厂接管要求；
- 污水处理厂尾水标准；
- 回用水用途标准；
- 受纳水体功能信息。

### 废气

- 项目行业和工艺适用的大气排放标准；
- VOCs有组织、厂界和厂区内控制要求；
- 恶臭和燃烧废气标准；
- 标准替代关系和生效日期。

### 噪声

- 声环境功能区划文件；
- 工业企业厂界噪声标准；
- 项目位置与区划单元对应材料。

### 固体废物

- 固体废物相关法律和地方条例；
- 一般工业固废贮存标准；
- 国家危险废物名录；
- 危险废物贮存标准；
- 废物鉴别和分类文件。

所有资料应登记在`shared/reference_bundle_manifest_template.yaml`中。
