## 1. 当前数据准备结论

- 中期汇报；
- 论文方法章节；
- 小规模知识条件对照实验设计；

- “大模型可替代人工审核”的结论。

关键原因是：候选题已经有了，但人工金标证据链尚未补齐。

## 4. 参考 Chen 论文后的简化对应

Chen 的复杂流程可以简化为：

```text
权威材料 -> 结构化任务 -> 专家/人工验证 -> 对照评价
```

对应到本课题：

```text
标准/指南/报告/修改意见/批复
-> 标准依据库 + 审核技能库 + 样本链 QA
-> 人工金标复核
-> A/B/C/D 知识条件对照实验
```

本课题不做微调，因此不需要准备大规模训练集。当前最需要的是小规模、高可信、证据可追溯的评价集。

## 6. 当前不要做的事

- 不要继续盲目扩充 942 题规模。
- 不要把 1037 行 QA 主表整体当正式测试集。
- 不要把 95 条样本链 QA 默认视为金标。
- 不要把 49 个数据库候选项目都称为完整样本链。
- 不要在人工金标未完成前跑正式 A/B/C/D 结论。
- 不要把 Chen、Kumar、Agent Skills 文献材料混入环评审核知识库。

## 7. 当前最应该做的事

先做一个小而可靠的评价闭环：

```text
60 道正式候选题
-> 人工复核 10-15 道样例
-> 补齐报告页码、标准条款、专家意见和人工答案
-> 扩展到 40-60 道 verified gold
-> 再运行 A/B/C/D 对照实验
```

第一阶段目标：

```text
10-15 道人工复核样例题
每题绑定 1 个主 skill
每题绑定至少 1 条标准依据
每题绑定报告证据和专家意见来源
```

第二阶段目标：

```text
40-60 道 verified gold
240 条 A/B/C/D 运行记录
人工评分和错误分析
```
