# 国民经济行业分类审核

## 1. Skill结构

本Skill覆盖环评报告中"一、建设项目基础情况"→"国民经济行业类别"的审核，依据产品、原料、工艺和用途判定行业分类是否正确。

```text
01 国民经济行业分类审核
├─ A 信息提取（产品、原料、工艺、填报类别）
├─ B 项目概述总结
├─ C 行业分类匹配
├─ D 比对与结论
└─ E 输出结论
```

## 2. 输入

```json
{
  "question_id": "",
  "question": "",
  "report_context": "",
  "reference_mode": "embedded_verified_classification"
}
```

报告上下文不得包含Word批注、修订痕迹和人工修改意见。

## 3. 审核总流程

### 第一步：信息提取

从报告以下位置提取四类关键信息：

| 序号 | 提取内容 | 提取位置 | 说明 |
|------|----------|----------|------|
| ① | 产品名称、产品备注 | "二、建设项目工程分析"→表2-2"项目主要产品产能一览表" | 提取所有产品的名称、产能、单位和备注 |
| ② | 主要原辅材料 | "二、建设项目工程分析"→表2-7"原料材料年用量一览表" | 提取所有物料名称 |
| ③ | 生产工艺 | "二、建设项目工程分析"→"工艺流程简述" | 总结项目设计的核心生产工艺 |
| ④ | 填报行业类别 | "一、建设项目基础情况"→"国民经济行业类别" | 提取项目编写的行业代码和名称 |

提取时需注意：
- 产品名称应提取"最终对外产品"，不是中间物料或边角料；
- 原料名称应提取"主要基材"，如树脂颗粒、原纸、外购薄膜等；
- 工艺应提取"决定产品材料形态、功能或用途的关键加工"，不是包装、搬运等末端动作；
- 填报类别需同时提取代码和名称（如C2929塑料零件及其他塑料制品制造）。

### 第二步：项目概述总结

根据提取的信息，总结形成项目概述，使用固定句式：

> 使用xxx原料，通过xxx工序，生产用于xxx的xxx产品。

举例：
- 使用塑料粒，通过注塑成型，生产用于家用电器配件、日用品配件的注塑配件。
- 使用PE塑料粒，通过吹膜工艺，生产用于不锈钢保护膜的塑料薄膜。
- 使用SEBS和增粘树脂，通过混料、双螺杆挤出、水下切粒，生产用于改性塑料的SEBS塑料粒料。

若一句话中出现两个互不依赖的最终产品，拆成两条活动分别总结。

### 第三步：行业分类匹配

根据项目概述，从《2017年国民经济行业分类注释》（GB/T 4754-2017，按第1号修改单修订）中匹配相符的国民经济行业类型。

匹配方法：
1. 按最终产品名称查询分类注释中的大、中、小类解释；
2. 核对小类的"指……"定义及"包括""不包括"项；
3. 检查近邻小类，做排除判断；
4. 由小类向上检查中类、大类、门类，防止名称相似但经济活动性质不同。

**有内置分类注释时**：使用`scripts/search_industry_classification.py`检索，或直接查询`references/2017国民经济行业分类注释_按第1号修改单修订.xlsx`。

**无内置分类注释时（参数知识辅助判断）**：可使用模型预训练中获得的国民经济行业分类知识（如C2929对应"其他塑料制品制造"、C2921对应"塑料薄膜制造"等），做初步判断，但必须：
- 在`external_validation_result.status`中标注`parameter_estimated`；
- 在`scope_note`中说明"分类基于模型参数知识，未经外部分类注释原文核验"；
- 不得将参数知识结论等同于已验证结论。

### 第四步：比对与结论

将识别判定的行业类别与项目填报的行业类别进行比对：

| 比对结果 | 判定结论 | 条件 |
|----------|----------|------|
| 代码与名称完全一致 | 正确 | 产品—工艺—用途与分类注释相符，且与填报一致 |
| 代码或名称不一致 | 需复核 | 写明识别类别、填报类别和具体差异 |
| 关键证据缺失 | 需复核 | 写明缺少产品、工艺、用途或分类依据中的哪一项 |

**禁止将"无内置分类注释"等同于"无法判断"。** 无内置注释时，应完成内部审核并用参数知识做初步判断。

### 第五步：输出结论

按照以下格式输出最终结论：

```text
1、国民经济行业类型判定结论：正确/需复核；
2、具体分析：根据项目概况，本项目主要通过xxx生产工艺，生产xxxx产品，经识别判定国民经济行业Cxxxx（小类编号+行业类别名称），与项目填报的国民经济行业类别Cxxxx（小类编号+行业类别名称）一致/有差异需要复核确认。
```

举例：
```text
1、国民经济行业类型判定结论：正确；
2、具体分析：根据项目概况，本项目主要通过注塑成型、铣床、磨床、火花机加工等生产工艺，生产家用电器、日常用品的注塑配件以及注塑用的注塑模具，经识别判定国民经济行业为C2929塑料零件及其他塑料制品制造、C3525模具制造，与项目填报内容一致。
```

## 4. 统一双层结论

### 第一层：报告内部审核

输出`report_internal_result`，包含：

- `status`：`pass`（内部一致无矛盾）| `issue_found`（发现内部矛盾）| `partially_verified`（部分可核验）| `insufficient_report_evidence`（报告关键证据缺失）；
- `evidence`：从报告中提取的产品、原料、工艺、填报类别等证据；
- `checks`：逐项判定结果；
- `issues`：具体问题描述。

### 第二层：外部分类核验

输出`external_validation_result`，包含：

- `status`：
  - `verified`：有内置分类注释且已逐项核验；
  - `parameter_estimated`：无内置分类注释，使用参数知识做初步判断，未经外部原文核验；
  - `not_required`：纯内部审核题；
  - `insufficient_reference`：有分类注释但关键条目缺失；
  - `not_performed`：既无分类注释也无法用参数知识判断。
- `conclusion`：核验结论；
- `references_used`：使用的参考资料；
- `missing_references`：缺失的参考资料。

### 最终结论

`final_answer.judgement`：

- **正确**：内部审核通过且分类核验确认（或参数知识判断一致）；
- **存在问题**：内部审核发现矛盾或分类错配；
- **部分完成**：报告内部一致但外部分类注释未核验；
- **待人工复核**：报告关键事实缺失，无法完成判断。

## 5. 常见误判提醒

- 看到"塑料粒"就判塑料制品业：原料不等于最终产品，需看最终产品性质；
- 看到"印刷机"就另列印刷业：自用标识印刷可能只是主产品的辅助工序；
- 只查小类名称不查注释：边界往往写在"包括/不包括"中；
- 一开始就用尾数为9的"其他"类：应先排除更具体小类；
- 把建设项目环评分类管理名录条目当成国民经济行业代码：两套分类目的和层级不同。

## 6. 禁止事项

- 禁止仅按原料关键词直接定类；
- 禁止把建设项目环境影响评价分类管理名录类别当作国民经济行业类别；
- 禁止硬编码任何测试项目答案；
- 禁止读取或恢复Word批注和人工修改意见；
- **允许使用模型参数知识做初步判断**，但必须标注`parameter_estimated`，不得等同于已验证结论。
