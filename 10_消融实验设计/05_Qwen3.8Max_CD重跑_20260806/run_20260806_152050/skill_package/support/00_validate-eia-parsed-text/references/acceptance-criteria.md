# 环评解析文本验收标准

## 1. 审核等价原则

验收目标不是复刻 Word 排版，而是保证解析文本可以替代 Word 成为人工审核的主要阅读输入。审核人员应能据此：

1. 找到决定性事实；
2. 判断事实属于哪个项目、工序、污染物或设施；
3. 复核数值、单位、公式和前后一致性；
4. 形成与阅读原 Word 基本相同的审核结论；
5. 在需要时返回原 Word 定位证据。

## 2. 五道验收门

| 验收门 | 可用门槛 | 典型阻断项 |
|---|---|---|
| G1 主体完整 | 原 Word 中存在的主章节全部保留、顺序一致 | 整章缺失、章节中途截断、跨章错拼 |
| G2 关键证据 | 人工抽查的决定性证据保留率不低于 95% | 产品、工艺、污染物、治理设施或结论缺失 |
| G3 数值与结构 | 关键数值—单位对保留率不低于 95%；关键表格字段归属明确 | 数值错位、单位丢失、表格串行后无法判断对应关系 |
| G4 可追溯 | 章节、表号、页码或稳定分块 ID 至少保留一种可靠定位 | 无法定位、分块重复/缺失造成证据链断裂 |
| G5 文本洁净 | 无解析器内部对象、异常栈、乱码和大段无意义重复 | `{'id': ...}`、`[object Object]`、未闭合表格、乱码 |

五道门全部通过才能判为 `可用`。G2 或 G3 出现决定性证据缺失时，不允许用其他维度高分抵消。

## 3. 自动指标默认阈值

自动指标用于发现风险，不机械替代人工抽查：

| 指标 | 通过 | 需人工确认 | 默认失败信号 |
|---|---:|---:|---:|
| 主章节存在与顺序 | 100% | — | 任一原有主章节缺失或乱序 |
| 主体正文 7 字符片段覆盖 | ≥90% | 80%–90% | <80% |
| 单章片段覆盖 | ≥90% | 75%–90% | 任一核心章节 <75% |
| 数值及单位出现次数覆盖 | ≥95% | 90%–95% | <90% |
| 审核关键表格覆盖 | ≥85% | 50%–85% | <50% 或字段归属错误 |

说明：页眉页脚、目录、重复标准全文、附件图片清单和纯排版文本可从覆盖率分母中排除，但必须说明排除范围。第六章后的附图、营业执照、身份证、合同等附件，可按实际审核任务决定是否纳入；正文、附表、监督检查清单和决定性附件不得静默排除。

## 4. 审核关键证据抽查清单

优先从下列类别各抽 1–2 项，总量控制在 8–12 项：

| 类别 | 最低抽查内容 |
|---|---|
| 项目基本情况 | 项目名称、地点、行业类别、总投资和环保投资 |
| 建设内容 | 产品及产量、主要原辅材料及用量、主要设备及数量 |
| 工艺与产污 | 完整工艺步骤、产污节点、污染物名称和排放形式 |
| 定量核算 | 活动水平、产污系数、收集效率、处理效率、产生量和排放量 |
| 废气治理 | 收集形式、风量、治理工艺、活性炭参数和排气筒信息 |
| 废水与噪声 | 水量/去向/处理方式，主要噪声设备与降噪措施 |
| 固废与危废 | 产生环节、名称、代码、数量、贮存和处置去向 |
| 标准与总量 | 标准名称/编号/限值，VOCs等总量指标及正文—附表一致性 |
| 监督检查清单 | 污染源、污染物、治理措施和执行标准对应关系 |

抽查时优先选择会影响审核结论的复杂表格和数值，不要只抽项目名称等容易保留的字段。

## 5. 可接受差异

- 字体、字号、颜色、分页和缩进变化；
- 删除页眉页脚、空白行、重复表头和目录点线；
- HTML、Markdown 或纯文本之间的标记差异；
- 上下标转成可读的普通字符，如 `m²` 转成 `m2`；
- 图片已由正文完整复述时省略图片本体；
- 合并空单元格或装饰性单元格，但不改变字段归属。

## 6. 阻断项

出现以下任一项，原则上判为 `不可用`：

- 缺少建设内容、工程分析、主要环境影响和保护措施或监督检查清单等主体内容；
- 大段内容在分块边界处无提示消失；
- 表格行列展开后，无法判断数值属于哪个污染物、工序或设施；
- 决定性数值、单位、小数点、正负号或百分比发生变化；
- 公式只剩结果，变量和运算关系丢失；
- 工艺流程图、平面关系图或图片表格承载独有证据，但没有文本替代；
- 混入序列化对象、代码、异常信息或乱码，导致正文被污染；
- 分块错序、重复或漏块，并造成证据缺失；
- 解析结果看似流畅，但将“不提供”改写为“不存在”等语义变化。

## 7. 轻量化评价

分别报告：

- 原 Word 文件大小；
- 解析结果文件大小；
- 原 Word 可见正文字符数；
- 解析后纯文本字符数；
- 解析后 token 数（若解析器提供）；
- 关键证据保留情况。

文件大小降低主要来自图片和 Office 结构，不能直接证明大模型输入变轻。优先用纯文本字符数或同一 tokenizer 的 token 数衡量输入压缩，并把保真验收作为先决条件。
