# Kumar 2025 方法与本课题数据流映射

## 1. 文章方法抽象

Kumar et al. 2025 的方法可以抽象为：

```text
大规模环境/LCA文献
  -> 元数据和全文抽取
  -> 专家标注相关/不相关样本
  -> 分类模型筛选相关文献
  -> 相关全文构成领域语料
  -> 专家构造 Q&A 数据
  -> RAG 检索源文档证据
  -> LLM 输出 LCI/环境影响答案
  -> 专家、文献、数据库验证
```

对应到本课题，建议改写为：

```text
地方标准/塑胶指南/环评报告/专家意见/批复
  -> 标准条目、报告片段、专家意见、批复条件结构化
  -> 人工筛选塑胶行业与完整样本链项目
  -> 构建标准依据库、审核技能库、样本链证据库
  -> 专家意见和技术评估意见转化为审核 QA
  -> RAG 检索报告证据、标准依据和专家意见
  -> LLM 生成辅助审查意见
  -> 人工/专家按照评分维度复核
```

## 2. 可复用模块

### 模块 1：数据来源分层

Kumar 将数据区分为原始文献、摘要、相关全文、Q&A 数据和验证数据库。本课题也应明确分层：

| 层级 | 本课题数据 | 作用 |
|---|---|---|
| L1 权威依据层 | 标准规范、塑胶指南、地方政策 | 提供审查依据 |
| L2 技能流程层 | 15 个审核技能 + 总审核技能 | 提供审查步骤 |
| L3 样本链证据层 | 公示版、报批稿、评估意见、批复 | 提供真实项目证据 |
| L4 候选任务层 | 942 条候选 QA | 覆盖审核任务类型 |
| L5 金标候选层 | 95 条样本链 QA | 构建正式评价题 |
| L6 正式评价层 | 计划筛选 40-60 条人工精校题 | 用于 A/B/C/D 实验 |

### 模块 2：人工标注优先

Kumar 的分类数据和 Q&A 数据均由 LCA 专家参与标注。本课题应采用同样原则：

- 样本链 QA 只作为金标候选；
- 正式评价题必须人工复核；
- 对自动生成题保留候选状态；
- 评分结果需要人工或专家确认。

### 模块 3：证据检索而不是自由问答

Kumar 的 RAG 用来检索文献证据。本课题的 RAG 应检索：

- 报告正文；
- 标准依据；
- 专家意见；
- 修改说明；
- 批复条件。

输出时必须体现“依据来自哪里”，否则不进入正式评分。

### 模块 4：外部基准验证

Kumar 使用 USLCI、文献和专家作为验证基准。本课题对应的验证基准为：

- 标准条款；
- 专家修改意见；
- 技术评估意见；
- 环评考核表或评分表；
- 批复文件；
- 人工复核答案。

## 3. 不建议采用的部分

| Kumar 方法 | 本课题是否采用 | 理由 |
|---|---|---|
| 分类微调 | 暂不采用 | 当前课题不是训练模型，样本规模也不足以支撑稳定微调 |
| 领域继续预训练 | 不采用 | 成本高，且偏离“知识库/技能库/评价方法”主线 |
| Q&A 微调 | 不采用 | 本课题更适合做知识条件对照，而不是训练问答模型 |
| 大规模文献 API 抽取 | 部分采用思想 | 本课题数据主要来自环评数据库、地方标准和项目样本链 |
| Hugging Face 模型发布 | 不采用 | 当前目标是硕士论文方法与数据集整理，不是发布模型 |

## 4. 对当前数据集的启发

当前数据量已经满足中期和方法试点：

- 候选 QA：1037 条；
- 原有候选 QA：942 条；
- 样本链 QA：95 条；
- 近三年 C292 候选样本链：49 个；
- 本地代表性样本链：10 个；
- 标准依据与审核技能库已具备阶段性基础。

但参考 Kumar 的数据质量逻辑，正式实验仍需完成：

1. 从 95 条样本链 QA 中筛选 40-60 条；
2. 补充每题报告页码；
3. 补充每题标准条款；
4. 标注专家意见或技术评估意见来源；
5. 确认是否在终稿或批复中形成闭环；
6. 形成评分表和人工复核记录。

## 5. 可直接写入论文的方法表述

```text
Kumar 等在生命周期评价领域提出的 LLM 框架表明，环境领域专业数据抽取需要经历语料筛选、专家标注、问答任务构造、RAG 证据检索和外部基准验证等环节。本文借鉴其“专业语料-结构化任务-证据检索-人工验证”的方法思想，但不进行模型微调，而是将其迁移到佛山市塑胶行业环评技术审查场景，构建标准依据库、审核技能库和样本链证据库，并通过知识条件对照实验评价大模型在审查辅助中的作用。
```

## 7. 与 Chen 2026 的互补关系

- Chen 2026 更适合作为“环境领域 LLM 工作流化、模型分工、部署策略”的参考；
- Kumar 2025 更适合作为“环境专业数据抽取、专家标注、Q&A 构造、RAG 证据验证”的参考；
- 本课题应综合二者，但保持研究边界：不做微调，重点做知识库、技能库、样本链证据和人机协同评价。
