# 环保投资占比核算审核

## 1. Skill结构

本Skill覆盖环评报告中"一、建设项目基础情况"→"总投资""环保投资""环保投资占比"的核算审核，以及环保工程投资明细的一致性检查。

```text
02 环保投资占比核算审核
├─ A 信息提取（总投资、环保投资、填报占比、分项明细）
├─ B 比例计算（环保投资占比 = 环保投资 ÷ 总投资 × 100%）
├─ C 分项合计（环保工程分项合计 = Σ各分项金额）
├─ D 比对与结论
└─ E 输出结论
```

## 2. 输入

```json
{
  "question_id": "",
  "question": "",
  "report_context": ""
}
```

本Skill仅依赖报告事实，不需要法规知识库。

## 3. 审核总流程

### 第一步：信息提取

从报告以下位置提取关键信息：

| 序号 | 提取内容 | 提取位置 | 说明 |
|------|----------|----------|------|
| ① | 总投资（万元） | "一、建设项目基础情况"→"总投资（万元）" | 提取项目总投资金额及单位 |
| ② | 环保投资（万元） | "一、建设项目基础情况"→"环保投资（万元）" | 提取环保投资金额及单位 |
| ③ | 填报的环保投资占比（%） | "一、建设项目基础情况"→"环保投资占比（%）" | 提取报告填报的占比数值 |
| ④ | 环保工程投资明细 | "二、建设项目工程分析"→环保工程投资估算表 | 提取各分项名称、金额和单位 |

提取时需注意：
- 金额单位统一为"万元"，如有"元"需换算；
- 占比数值保留报告原有小数位数；
- 环保工程投资明细表可能位于不同章节，需搜索"环保投资""环保工程""投资估算"等关键词定位；
- 若报告中未单独列出环保工程投资明细表，仅审核总投资、环保投资和占比三项。

### 第二步：比例计算

根据公式核算环保投资占比：

> **环保投资占比（%）= 环保投资 ÷ 总投资 × 100%**

计算要求：
- 保留与报告相同的小数位数；
- 记录原始计算值和四舍五入后的显示值；
- 若环保投资或总投资缺失，无法完成计算，标注为"关键金额缺失"。

### 第三步：分项合计（如有明细）

若报告包含环保工程投资明细表：

> **环保工程分项合计 = Σ各分项金额**

核对：
- 分项合计与环保投资总额是否一致；
- 各分项金额单位是否统一；
- 是否存在重复项或漏项。

### 第四步：比对与结论

将核算结果与报告填报值逐项比对：

| 比对项 | 比对内容 | 判定条件 |
|--------|----------|----------|
| 占比核算 | 核算占比 vs 填报占比 | 差额仅为显示精度舍入差异→正确；否则→错误 |
| 分项合计 | 分项合计 vs 环保投资 | 金额一致→正确；不一致→存在问题 |
| 单位口径 | 不同表格中的金额单位 | 统一换算后一致→正确；存在冲突→存在问题 |
| 跨表一致 | 基本情况表 vs 环保工程表 | 同一金额在两处一致→正确；不一致→存在问题 |

**容差规则**：
- 金额差额必须为0，或明确说明差额来源；
- 百分比可按报告小数位数进行四舍五入比较；
- 不得用任意5%或10%误差掩盖计算错误。

### 第五步：输出结论

按照以下格式输出最终结论：

```text
1、环保投资占比（%）核算正确/错误；
2、具体分析：项目填报的项目总投资金额xx万元，环保投资金额XX万元，经核算环保投资占比为xx%，与填报的环保投资占比xx%相符或不相符需复核修改。
```

举例：
```text
1、环保投资占比（%）核算正确；
2、具体分析：项目填报的项目总投资金额100万元，环保投资金额15万元，经核算环保投资占比为15.00%，与填报的环保投资占比15.00%相符。
```

若存在分项明细不一致，在具体分析后补充：
```text
环保工程投资明细各分项合计为XX万元，与环保投资总额XX万元一致/不一致，差额XX万元。
```

## 4. 统一双层结论

### 第一层：报告内部审核

输出`report_internal_result`，包含：

- `status`：
  - `pass`：占比核算正确，分项合计一致，无前后矛盾；
  - `issue_found`：占比计算错误、分项合计不等或跨表不一致；
  - `partially_verified`：部分项目可核验，但关键金额缺失；
  - `insufficient_report_evidence`：总投资、环保投资或占比等关键数据均缺失。
- `evidence`：从报告中提取的总投资、环保投资、占比、分项明细等证据；
- `checks`：逐项判定结果（占比核算、分项合计、单位口径、跨表一致性）；
- `calculations`：核算公式、输入值和结果；
- `issues`：具体问题描述。

### 第二层：外部规范核验

本Skill仅依赖报告内部数据，不需要外部法规知识库。

输出`external_validation_result`：
- `status`：固定为`not_required`；
- `conclusion`："本Skill为纯报告内部核算审核，不需要外部规范核验。"

### 最终结论

`final_answer.judgement`：

- **正确**：占比核算正确，分项合计一致，无前后矛盾；
- **存在问题**：占比计算错误、分项合计不等、单位冲突或跨表不一致；
- **部分完成**：部分数据可核验，但关键金额缺失无法完成全部审核；
- **待人工复核**：总投资或环保投资缺失，无法完成判断。

## 5. 常见误判提醒

- 只看基本情况表不看环保工程表：需跨表核对同一金额；
- 单位不统一直接比较：元和万元混用时必须先换算；
- 用大误差容忍掩盖计算错误：仅允许显示精度造成的舍入差异；
- 忽略分项漏项或重复：分项合计应等于环保投资总额；
- 未计算直接采信填报值：必须独立复算占比，不得直接采信。

## 6. 禁止事项

- 禁止不计算直接采信报告填报的占比；
- 禁止用任意容差掩盖计算错误；
- 禁止忽略跨表金额不一致；
- 禁止硬编码任何测试项目答案；
- 禁止读取或恢复Word批注和人工修改意见；
- 禁止将本Skill用于非环保投资核算的其他审核。
