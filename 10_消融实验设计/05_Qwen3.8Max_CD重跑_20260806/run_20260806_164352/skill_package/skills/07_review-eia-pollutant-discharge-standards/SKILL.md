# 污染物排放控制标准审核

## 1. Skill结构

本Skill覆盖21题中的13道排放标准题，按介质分为4个子流程：

```text
07 污染物排放控制标准审核
├─ A 废水排放标准判定
├─ B 大气排放标准判定
├─ C 噪声排放标准判定
└─ D 固体废物控制标准判定
```

标准知识检索由支持模块`retrieve-eia-discharge-standard-knowledge`提供，不作为独立审核结论。

## 2. 输入

```json
{
  "question_id": "",
  "question": "",
  "medium": "wastewater | air | noise | solid_waste",
  "report_context": "",
  "reference_bundle": []
}
```

`reference_bundle`为空时，仍执行报告内部审核，并可使用模型参数知识做初步判断。

## 3. 审核总流程

### 第一步：提取

从报告"三、区域环境质量现状、环境保护目标及评价标准"→"污染物排放控制标准"整部分内容中提取：

1. 四类排放标准是否编制齐全（水、大气、噪声、固体废物）；
2. 对应介质子流程所需的具体内容。

### 第二步：报告内部审核

对提取内容执行内部一致性检查（详见各子流程）。

### 第三步：知识库对比（有RAG时）

有`reference_bundle`时，将报告内容与标准原文逐项对比。

### 第四步：参数知识辅助判断（无RAG时）

无`reference_bundle`时，可使用模型预训练中获得的参数知识（如标准限值、适用范围）做**初步判断**，但必须：
- 在`external_validation_result.status`中标注`parameter_estimated`；
- 在`scope_note`中说明"限值基于模型参数知识，未经外部标准原文核验"；
- 不得将参数知识结论等同于已验证结论。

## 5. A：废水排放标准判定

### 提取

从报告"污染物排放控制标准"→"水污染物排放标准"中提取：

1. 生活污水预处理执行标准；
2. 排入的污水处理厂名称；
3. 尾水排放河道；
4. 尾水排放执行标准；
5. 排放执行标准表格的限值数据。

### 判定内容

| 序号 | 判定项 | 判定方法 |
|------|--------|----------|
| ① | 生活污水预处理排放标准是否正确 | 对比知识库或参数知识中该标准的适用范围和限值 |
| ② | 识别排入的污水处理厂名称 | 从报告各章节提取，判断是否一致 |
| ③ | 尾水排放河道是否正确 | 根据污水处理厂名称，判断尾水排放河道描述是否合理 |
| ④ | 尾水排放标准是否正确 | 对比知识库或参数知识中该标准的适用范围 |
| ⑤ | 排放标准表格限值数据 | 逐项核对表格中的CODcr、BOD5、NH3-N、SS等限值数值 |

### 输出结论格式

- **无误**：生活污水排放标准、污水处理厂名称、尾水河道、尾水标准、表格限值均正确；
- **存在缺漏**：缺少某项内容（如未提及尾水标准）；
- **存在错误**：某项内容有误（如标准限值填写错误、河道名称错误）。

## 6. B：大气排放标准判定

### 提取

1. 从"二、建设项目工程分析"→"项目各工序产污情况一览表"提取废气产污环节、污染源名称和主要污染物；
2. 从"二、建设项目工程分析"→"主要原辅材料及能源消耗一览表"判断是否含有聚氯乙烯（PVC）或其他合成树脂原料；
3. 从"三、区域环境质量现状..."→"污染物排放控制标准"→"大气污染物排放标准"提取标准内容（文段+表格）。

### 判定内容

| 序号 | 判定项 | 判定方法 |
|------|--------|----------|
| ① | 污染源覆盖完整性 | 对照产污环节一览表，检查大气标准分析中是否对所有工序、污染物都有对应标准描述 |
| ② | 标准-工序-污染物-排放形式匹配 | 对每个污染源，核对"工序+污染因子+排放形式（有组织/无组织）+执行标准"四要素是否完整且正确 |
| ③ | 特征污染物识别 | 若原料含合成树脂（如PVC、聚酰胺等），根据GB31572-2015表4查找对应树脂类型的特征污染物（如氨、氯乙烯等）及排放限值，判断报告是否遗漏 |
| ④ | 排放限值表格数据 | 根据表头信息识别排放形式和污染因子，逐项核对限值数值 |

### 特征污染物对照

当原辅材料含合成树脂时，从GB31572-2015表4"适用的合成树脂类型"查找：

```text
原料/树脂 → 特征污染物 → 排放限值 → 与报告填报对比
```

例如：聚酰胺树脂→特征污染物"氨"→排放限值30mg/m³→检查报告大气污染物排放标准表格中是否包含氨及限值是否正确。

### 输出结论格式

- **完整/不完整**：污染源覆盖是否完整（不完整时列出缺少的工序/污染物）；
- **相符/不相符**：各污染因子排放执行标准描述是否与知识库/参数知识相符（不相符时列出错误项）；
- **无误/存在错误**：排放限值数据是否正确（存在错误时列出污染物+错误限值+正确限值）。

## 7. C：噪声排放标准判定

### 提取

1. 从"三、区域环境质量现状"→"声环境质量现状"提取项目厂界所属声功能类型；
2. 从"污染物排放控制标准"→"噪声排放标准"提取：声功能区类型+执行标准名称+昼间/夜间标准值。

### 判定内容

| 序号 | 判定项 | 判定方法 |
|------|--------|----------|
| ① | 声功能区类型是否正确 | 对比区域环境现状中的数据，判断功能区类别（如2类/3类）是否合理 |
| ② | 执行标准名称是否正确 | 核对是否为GB12348-2008《工业企业厂界环境噪声排放标准》，而非误用GB3096-2008《声环境质量标准》 |
| ③ | 噪声限值是否正确 | 根据声功能区类型+知识库/参数知识，核对昼间/夜间标准值是否正确（如3类：昼65/夜55dB(A)） |

### 输出结论格式

- **无误**：功能区类型、执行标准名称、昼间/夜间限值均正确；
- **功能区编制错误**：声功能区类型判定有误；
- **执行标准编制错误**：误用标准名称（如将排放标准写成质量标准）；
- **噪声限值编制错误**：昼间或夜间限值数值有误。

## 8. D：固体废物控制标准判定

### 提取

从"污染物排放控制标准"→"固体废物控制标准"提取执行标准表述（需表述完整，包括括号内修订内容）。

### 判定内容

固体废物执行标准应包括：

1. 《中华人民共和国固体废物污染环境防治法》（2020年修正）；
2. 《广东省固体废物污染环境防治条例》（2018年修订）。

危险废物执行标准应包括：

1. 《国家危险废物名录》（2025年版）；
2. 《危险废物贮存污染控制标准》（GB18597-2023）；
3. 《危险废物收集 贮存 运输技术规范》（HJ2025-2012）；
4. 《建设项目危险废物环境影响评价指南》（环保部公告2017年第43号）。

### 判定方法

逐项核对报告中是否提及上述标准，是否使用了正确的版本和修订年份。

### 输出结论格式

- **无误**：固体废物和危险废物执行标准内容齐全且版本正确；
- **缺少固体废物/危险废物执行标准**：列出缺少的标准名称；
- **版本错误**：列出使用错误版本的标准及正确版本。

## 9. 统一双层结论

### 第一层：报告内部审核

输出`report_internal_result`，包含：

- `status`：`pass`（内部一致无矛盾）| `issue_found`（发现内部矛盾）| `partially_verified`（部分可核验）| `insufficient_report_evidence`（报告关键证据缺失）；
- `checks`：逐项判定结果（无误/存在缺漏/存在错误）；
- `issues`：具体问题描述。

### 第二层：外部规范审核

输出`external_validation_result`，包含：

- `status`：
  - `verified`：有RAG且已逐项核验限值；
  - `parameter_estimated`：无RAG，使用参数知识做初步判断，未经外部原文核验；
  - `not_required`：纯内部审核题（如投资核算）；
  - `insufficient_reference`：有RAG但关键限值表缺失，仅确认适用范围；
  - `not_performed`：既无RAG也无法用参数知识判断。
- `conclusion`：核验结论；
- `references_used`：使用的参考资料；
- `missing_references`：缺失的参考资料。

### 最终结论

`final_answer.judgement`：

- **正确**：内部审核通过且外部核验确认（或参数知识判断一致）；
- **存在问题**：内部审核发现矛盾或限值填写错误；
- **待人工复核**：报告关键证据缺失，无法完成判断。

**禁止将"无RAG"等同于"无法判断"。** 无RAG时，应完成内部审核并用参数知识做初步判断，在`scope_note`中标注"参数知识初步判断，未经外部核验"。

## 10. 禁止事项

- 不把报告自己引用的标准视为已经被外部验证（需独立核验）；
- 不因为标准编号相似就认定适用；
- 不读取Word批注和人工修改意见；
- 不硬编码任何测试项目答案；
- **允许使用模型参数知识做初步判断**，但必须标注`parameter_estimated`，不得等同于已验证结论。
