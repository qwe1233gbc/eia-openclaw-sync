# 文件类型与环评审核流程作用说明

> 目的：说明当前项目中每类文件的作用，以及它们在环评技术审查流程中的位置。  
> 适用范围：佛山市塑胶行业环评技术审查知识库、技能库、样本链证据库与大模型辅助评价研究。  
> 核心原则：不是所有文件都进入正式实验；文件要按“审核流程作用”和“证据可信等级”分层使用。

## 1. 一句话总览

当前项目文件可以分成 8 类：

1. **研究说明类文件**：说明课题边界、数据状态和使用方法；
2. **标准依据类文件**：提供“审查依据是什么”；
3. **审核技能类文件**：提供“应该怎么审”；
4. **样本链原始材料**：提供“真实项目证据在哪里”；
5. **专家意见与评分材料**：提供“真实审核问题是什么”；
6. **QA 与评价任务文件**：提供“用什么题评价大模型辅助效果”；
7. **实验设计与运行文件**：提供“怎么做 A/B/C/D 对照实验”；
8. **论文与中期汇报文件**：提供“如何写论文和汇报”。

其中，最核心的是：

```text
标准依据类文件 + 审核技能类文件 + 样本链原始材料 + 专家意见/评分材料 + QA评价任务文件
```

这五类共同构成你的论文数据主线。

## 2. 按环评审核流程理解每种文件

环评技术审查可以简化为以下流程：

```text
项目进入受理/公示
  -> 审查报告正文
  -> 对照标准和地方指南
  -> 形成专家意见或技术评估意见
  -> 编制单位修改完善
  -> 报批稿/终稿形成
  -> 行政批复
  -> 后续形成知识库、技能库和评价任务
```

你的文件对应关系如下：

| 审核阶段 | 对应文件类型 | 文件作用 | 在本课题中的作用 |
|---|---|---|---|
| 受理/公示阶段 | 受理公告、公示版报告 | 说明项目公开受理信息和公开版报告内容 | 确认项目真实性、项目名称、建设单位、公开文本 |
| 报告技术审查阶段 | 报批稿、终稿、报告正文 | 审查建设内容、工艺、原辅料、污染物、治理措施、标准适用 | 提供模型和人工审核的报告证据 |
| 标准对照阶段 | 标准文件、地方指南、三线一单、产污系数、排放标准 | 判断报告依据是否正确 | 构建标准依据库，支撑 B/D 组实验 |
| 专家审查阶段 | 修改意见、专家意见、技术评估意见、评分表 | 记录专家发现的问题和评分依据 | 转化为样本链 QA，构建金标候选 |
| 修改完善阶段 | 修改说明、复核稿、终稿 | 判断专家意见是否被修改回应 | 构建“问题-修改-闭环”证据 |
| 批复阶段 | 批复文件 | 记录最终审批管理要求 | 核查专家意见是否进入批复条件 |
| 数据构建阶段 | QA 表、标准卡、技能库、样本链索引 | 把原始材料转成结构化研究数据 | 支撑论文方法和实验评价 |
| 实验评价阶段 | 金标候选表、人工复核表、A/B/C/D 实验表 | 组织模型输出和人工评分 | 支撑大模型辅助评价实验 |

## 3. 样本链四类核心文件的作用

### 3.1 受理公告 / 公示版

**常见位置：**

```text
05_样本链（按项目组织）/项目名/01_受理公告或公示版/
D:\华南理工项目\智慧环评\中期答辩\样本链_C292近三年精选_20260706\项目名\01_受理公告或公示版
```

**它是什么：**

项目进入受理或公示阶段时公开的材料，通常包括项目基本信息和公示版报告。

**在审核过程中的作用：**

- 确认项目是否真实存在；
- 确认建设单位、项目名称、建设地点；
- 查看公开版报告的基本内容；
- 判断项目是否属于佛山市塑胶行业研究范围。

**在本课题中的作用：**

- 作为样本链第一环；
- 用于项目身份核验；
- 不是最主要的审核问题来源；
- 不建议单独用它生成正式 QA。

**使用等级：**

中等。适合核实项目背景，不适合作为金标问题来源。

### 3.2 报批稿 / 终稿

**常见位置：**

```text
05_样本链（按项目组织）/项目名/02_报批稿或终稿/
D:\华南理工项目\智慧环评\中期答辩\样本链_C292近三年精选_20260706\项目名\02_报批稿或终稿
```

**它是什么：**

环评报告的正式文本或修改后的终稿，是技术审查的核心对象。

**在审核过程中的作用：**

- 审查建设内容是否完整；
- 审查原辅料、工艺流程、产污环节是否一致；
- 审查废气、废水、噪声、固废、危废等分析是否充分；
- 审查标准适用、源强核算、治理设施是否合理；
- 判断专家意见是否已经在终稿中修改。

**在本课题中的作用：**

- 是正式评价题必须绑定的核心证据；
- 后续人工金标题需要补充报告页码；
- 大模型回答不能只引用专家意见，还要回到报告正文核查。

**使用等级：**

很高。正式评价题必须尽量绑定报批稿或终稿中的证据位置。

### 3.3 修改意见 / 评估意见 / 技术评估意见

**常见位置：**

```text
05_样本链（按项目组织）/项目名/03_修改意见或评估意见/
D:\华南理工项目\智慧环评\中期答辩\样本链_C292近三年精选_20260706\项目名\03_修改意见或评估意见
```

**它是什么：**

专家、评估单位或审查人员对报告提出的问题、修改要求或技术评估结论。

**在审核过程中的作用：**

- 记录真实审核发现的问题；
- 指出报告哪里不充分、不准确或需要补充；
- 体现地方审核经验；
- 反映专家关注的关键风险点。

**在本课题中的作用：**

- 是样本链 QA 的最高价值来源；
- 可以转化为“模型是否能发现该问题”的评价任务；
- 可以用于校准审核技能库；
- 可以用于说明地方审核经验如何结构化。

**使用等级：**

最高。优先用于构建金标候选题。

### 3.4 批复

**常见位置：**

```text
05_样本链（按项目组织）/项目名/04_批复/
D:\华南理工项目\智慧环评\中期答辩\样本链_C292近三年精选_20260706\项目名\04_批复
```

**它是什么：**

生态环境主管部门出具的行政批复文件，记录最终审批意见和环境管理要求。

**在审核过程中的作用：**

- 明确项目是否获批；
- 明确废气、废水、噪声、固废、危废等管理要求；
- 明确总量控制、执行标准和环保措施要求；
- 体现最终行政管理结论。

**在本课题中的作用：**

- 用于核查专家意见是否进入最终管理要求；
- 用于构建“专家意见-终稿修改-批复要求”闭环；
- 可用于批复一致性 QA；
- 不适合单独作为“模型应发现问题”的唯一依据。

**使用等级：**

高，但要和报告、专家意见一起使用。只有批复而没有报告和修改意见，不适合进入正式评价集。

## 4. 标准依据类文件的作用

### 4.1 原始标准 PDF

**常见文件：**

```text
03_指南解析_明文标准库/_source_downloads_v4/*.pdf
```

例如：

- `GB_31572-2015_2024...pdf`
- `GB_37822-2019.pdf`
- `HJ_1122-2020.pdf`

**它是什么：**

国家标准、行业技术规范或地方标准的原始文件。

**在审核过程中的作用：**

- 判断报告引用标准是否正确；
- 判断排放限值、治理要求、监测要求是否准确；
- 作为人工复核的最高依据之一。

**在本课题中的作用：**

- 是标准依据库的源文件；
- 用于校准标准卡；
- 用于正式评价题的标准条款绑定。

**使用等级：**

最高。正式金标题应尽量绑定到具体标准条款。

### 4.2 Dify 工作流知识库文件

**常见位置：**

```text
03_指南解析_明文标准库/Dify工作流知识库/
```

**它是什么：**

历史 Dify 工作流中整理的标准、速查表、行业分类、三线一单、产污系数、排放限值等知识材料。

**在审核过程中的作用：**

- 作为审查时快速查找标准和经验的知识材料；
- 支撑常见审核点的快速判断。

**在本课题中的作用：**

- 是标准依据库的重要候选来源；
- 可解析成标准卡；
- 不能未经校准直接作为权威标准。

**使用等级：**

中高。适合做候选库，正式使用前要人工校准。

### 4.3 标准卡文件

**常见文件：**

```text
03_指南解析_明文标准库/standard_cards.json
03_指南解析_明文标准库/standard_cards.jsonl
03_指南解析_明文标准库/STANDARD_CARDS.md
03_指南解析_明文标准库/cards_by_skill/
03_指南解析_明文标准库/cards_by_domain/
```

**它是什么：**

把原始标准、地方指南和知识库条目整理成结构化卡片。

**在审核过程中的作用：**

- 快速定位某个审核问题对应的标准依据；
- 支撑标准适用判断；
- 支撑模型引用依据。

**在本课题中的作用：**

- 是 B 组和 D 组实验的重要输入；
- 是标准依据库主线文件；
- 后续需要补充人工复核状态。

**使用等级：**

高。主标准卡可进入实验，但候选卡需要校准。

### 4.4 `cards_by_skill` 文件

**常见位置：**

```text
03_指南解析_明文标准库/cards_by_skill/
```

**它是什么：**

按照审核技能划分的标准依据集合。

**在审核过程中的作用：**

- 当审核某个问题时，快速调取该技能相关标准；
- 例如审核 VOCs 总量时调用 VOCs 总量控制相关标准。

**在本课题中的作用：**

- 连接标准库和技能库；
- 支撑 D 组“标准库 + 技能库”实验；
- 是后续技能-标准绑定的重要基础。

**使用等级：**

很高。建议作为后续实验的核心输入之一。

## 5. 审核技能类文件的作用

### 5.1 `SKILL.md`

**常见位置：**

```text
09_环评审核技能库/某审核技能/SKILL.md
```

**它是什么：**

每个审核技能的操作说明，描述该技能适用什么场景、需要看什么材料、怎么判断。

**在审核过程中的作用：**

- 把资深审核人员的经验步骤写成可复用流程；
- 指导新人按步骤核查；
- 指导大模型按审查逻辑输出。

**在本课题中的作用：**

- 是 C 组和 D 组实验的核心输入；
- 是你论文中“技能库”的主体；
- 说明你的研究不是普通知识库问答。

**使用等级：**

很高。应作为论文主线。

### 5.2 `config.yaml`

**它是什么：**

技能配置文件，通常用于说明技能名称、输入输出、依赖材料或调用设置。

**在审核过程中的作用：**

- 让审核技能具备可执行、可调用的结构；
- 明确每个技能需要哪些输入。

**在本课题中的作用：**

- 支撑工作流化和可复用性；
- 后续可用于实验自动化。

**使用等级：**

中高。方法章节可提，实验阶段可逐步使用。

### 5.3 `output_example.json`

**它是什么：**

某个审核技能的输出示例。

**在审核过程中的作用：**

- 规定模型或人工输出的格式；
- 便于统一不同审核任务的结果表达。

**在本课题中的作用：**

- 支撑评价表结构；
- 可用于约束大模型输出；
- 有助于后续人工评分。

**使用等级：**

中高。适合进入实验设计，不一定直接进入论文主文。

## 6. QA 与评价任务文件的作用

### 6.1 原始 942 QA 工作簿

**常见文件：**

```text
05_QA测试集/seed_qa_942题_151项目_phase1+phase2合并.xlsx
```

**它是什么：**

原有候选审核问题池，包含不同项目、不同审核模块的 QA。

**在审核过程中的作用：**

它本身不是实际审核文件，而是把审核问题转化成任务形式。

**在本课题中的作用：**

- 用于覆盖审核主题；
- 用于发现常见问题类型；
- 用于候选任务池；
- 不能直接作为正式测试集。

**使用等级：**

中。适合作为候选池，不适合作为最终金标。

### 6.2 样本链 95 QA 工作簿

```text

```

**它是什么：**

在原有 QA 基础上，加入 95 条样本链 QA 的版本。

**在审核过程中的作用：**

把真实专家意见、技术评估意见、评分表和批复核查转化成审核任务。

**在本课题中的作用：**

- 当前最重要的金标候选池；
- 后续从中筛选 40-60 条正式评价题；
- 支撑 A/B/C/D 对照实验。

**使用等级：**

很高，但仍需人工精校。

**它是什么：**

从 95 条样本链 QA 中筛选出的 60 条正式评价候选题。

**在审核过程中的作用：**

不直接属于实际审核流程，而是实验评价阶段的任务清单。

**在本课题中的作用：**

- 是下一步人工金标复核的核心对象；

人工复核模板，要求补充报告页码、标准条款、专家意见位置、终稿闭环、批复体现和人工参考答案。

**在审核过程中的作用：**

模拟专家复核过程，把候选题变成可评价金标题。

**在本课题中的作用：**

- 是当前最需要填写的文件；

**使用等级：**

最高。下一步核心文件。

outputs/next_execution_plan_20260706/skill_standard_binding_tasks.csv

每道正式评价候选题和审核技能、标准依据、报告证据之间的绑定任务表。

**在审核过程中的作用：**

把“一个问题应该怎么审、用什么标准、看报告哪里”连接起来。

**在本课题中的作用：**

- 是技能库和标准库真正落地的桥梁；

很高。建议和人工复核模板同步填写。

## 9. 正式环评审核过程中，每一步应该看哪些文件

### 第一步：确认项目是否属于研究范围

看：

- 受理公告/公示版；
- 报告基本信息；
- 国民经济行业分类；
- 塑胶行业技术指南；
- `02_适用行业与样本筛选/`；
- 标准库中的行业分类条目。

判断：

- 是否属于 C292 塑胶行业；
- 是否属于佛山市塑胶行业技术指南适用范围；
- 是否涉胶水、涂胶、复合、熟化或 VOCs 治理。

### 第二步：审查报告建设内容

看：

- 报批稿/终稿；
- 建设内容章节；
- 原辅料表；
- 设备清单；
- 工艺流程；
- `09_环评审核技能库/04_建设内容完整性审核/`。

判断：

- 产品、产能、设备是否一致；
- 原辅料是否完整；
- 工艺和产污节点是否对应；
- 是否存在漏报、错报或前后矛盾。

### 第三步：审查标准适用

看：

- 标准原文 PDF；
- 标准卡；
- Dify 标准候选条目；
- 报告执行标准章节；
- `cards_by_skill/06_环境质量执行标准`；
- `cards_by_skill/07_污染物排放标准`。

判断：

- 废气、废水、噪声、固废、危废标准是否正确；
- 是否错误适用特别排放限值；
- 是否遗漏地方标准或行业标准。

### 第四步：审查源强和治理措施

看：

- 报批稿/终稿源强核算章节；
- 产污系数；
- VOCs 物料平衡；
- 废气收集风量；
- 收集效率；
- 活性炭参数；
- 技能库 08-13。

判断：

- 源强核算依据是否合理；
- 废气收集方式是否匹配工艺；
- 风量、效率、活性炭参数是否合理；
- VOCs 产生、收集、处理、排放是否闭合。

### 第五步：审查固废、危废和风险

看：

- 报告固废章节；
- 危废识别表；
- 原辅料和污染物性质；
- 专家意见；
- 技能库 14；
- 标准库中 GB18597、GB18599 等条目。

判断：

- 危废类别是否遗漏；
- 危废暂存方式是否合理；
- 风险物质是否识别；
- 是否存在新污染物或特殊风险。

### 第六步：核对专家意见和修改说明

看：

- 修改意见；
- 技术评估意见；
- 评分表；
- 修改说明；
- 报批稿/终稿。

判断：

- 专家提出了哪些问题；
- 编制单位是否逐条回应；
- 终稿是否真实修改；
- 是否还有未闭环问题。

### 第七步：核对批复要求

看：

- 批复文件；
- 技术评估意见；
- 终稿；
- 专家意见。

判断：

- 批复是否体现关键环境管理要求；
- 批复条件是否与报告和专家意见一致；
- 是否形成“问题-修改-批复”闭环。

### 第八步：转化为 QA 和实验任务

看：

- 样本链 QA；
- `formal_eval_candidate_60.csv`；
- `gold_manual_review_template_60.csv`；
- `skill_standard_binding_tasks.csv`；
- `abcd_experiment_run_sheet.csv`。

判断：

- 哪些问题适合做正式评价题；
- 每道题是否有报告证据；
- 是否有标准条款；
- 是否有专家意见或批复支撑；
- 是否可以进入 A/B/C/D 实验。

## 11. 哪些文件不要混入正式实验

以下文件不要进入正式实验语料：

- 中期汇报稿；
- 文献综述材料；
- Chen/Kumar 方法总结；
- 未校准的 Dify 候选条目；
- 只有批复、没有报告和修改意见的单点材料；
- 无证据绑定的工作流生成 QA；
- 旧版本、备份版本和重复版本。

它们可以用于写作、参考或候选补充，但不应作为模型判断项目是否合规的依据。

## 12. 最终建议

当前你不需要再继续问“文件是不是越多越好”。下一步应该按流程使用文件：

```text
样本链原始材料
  -> 专家意见/技术评估意见
  -> 报告正文证据
  -> 标准条款
  -> 人工参考答案
  -> 正式评价题
  -> A/B/C/D 实验
```

最关键的下一步是填写：

```text
gold_manual_review_template_60.csv
```

只要这 60 条题完成报告页码、标准条款、专家意见来源、终稿闭环和人工参考答案，你的正式实验数据基础就基本成立。
