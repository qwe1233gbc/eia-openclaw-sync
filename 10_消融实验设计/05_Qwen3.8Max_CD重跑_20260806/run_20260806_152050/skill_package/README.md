# 21题 C组 Skill 重整版

## 一、重整后的结论

当前21道题不需要继续增加大量独立Skill。按题目类型，使用4个主Skill即可覆盖全部21题：

| 主Skill | 覆盖题数 | 说明 |
|---|---:|---|
| 01 国民经济行业类别审核 | 4 | 保留现有完整Skill，删除重复Skill和PL001专属案例 |
| 02 环保投资审核 | 1 | 在原占比复算基础上增加分项投资勾稽 |
| 05 环境质量现状数据审核 | 3 | 分开输出“报告内部核验”和“官方公报核验” |
| 07 污染物排放控制标准审核 | 13 | 内含废水、废气、噪声、固废4个子流程 |

另外保留2个支持模块：

- `00_validate-eia-parsed-text`：四组共用的报告解析质量门控，不计作实验Skill；
- `retrieve-eia-discharge-standard-knowledge`：标准资料解析和匹配支持模块，不单独作为一道审核Skill。

## 二、删除和合并

### 删除重复Skill

删除：

```text
review-eia-industry-classification
```

原因：与完整的`manual-audit-national-economic-industry-classification`重复。

### 删除项目专属案例

删除：

```text
references/liangzheng-case.md
```

原因：PL001属于测试项目，项目案例会造成答案泄漏。

### 不新增“行业分类报告内版”

行业分类Skill已经存在。本次只修改现有Skill，不再新建重复条目。

### 不把“种子样本适宜性”并入环评审核Skill

若原题同时询问行业分类和种子样本适宜性，优先拆成两题。样本适宜性属于数据集治理，不属于环境专业审核Skill。

## 三、C组的实验定义

本包适用于只运行C组时的“专业Skill可执行性实验”。

此时C组定义为：

```text
环评报告 + 大模型 + 模块化专业Skill
```

行业分类Skill可以携带稳定的分类注释工具；环境质量和排放标准Skill可以读取用户提供的正式参考资料包。

因此，本轮不能再表述为“纯程序约束、不含任何知识”，更准确的表述是：

> 模块化专业审核Skill包对环评审核任务的可执行性与输出质量验证。

只运行C组时，不能证明Skill相对于基础大模型带来了性能提升。若论文需要证明增益，至少保留A组作为基线。

## 四、减少无效安全阻拦的统一原则

所有Skill必须采用“双层结论”：

1. `report_internal_result`：报告内部事实、计算和章节一致性；
2. `external_validation_result`：外部标准、公报或分类依据的核验状态。

即使外部资料缺失，也不得把整道题压缩为一句“无法判断”。模型必须先完成能够完成的报告内部审核，再单独说明外部核验未完成。

## 五、正式实验输入要求

- 删除Word批注、修订痕迹和人工修改意见；
- 删除联系人、电话、身份证等个人信息；
- 不把人工答案、金标和项目专属案例输入模型；
- 每道题只提供该题所需的最小报告证据；
- 环境质量和排放标准若需要完整判断，应额外提供正式参考资料包。
