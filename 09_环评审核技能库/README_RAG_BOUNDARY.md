# RAG与Skill边界

Skill只规定抽取什么、审核顺序、计算和交叉核对方法、证据不足处理和输出结构。Skill不得包含具体测试题答案、项目级金标、PL题号写死结论、人工答案或正式RAG全文副本。

正式RAG回答“依据是什么”；Skill回答“怎样审核”。A/B不调用Skill，C/D只加载题型路由到的单项Skill，`99`汇总Skill不参与单题主生成。


## 知识常量与审核函数

- RAG提供标准、条款、限值、适用范围和版本等知识常量。
- Skill提供证据抽取、查询构造、比较、复算、降级和输出等审核函数。
- 经验库只提供带来源类型的风险提示，不能单独支撑结论。
- 报告JSON提供项目事实；报告证据与RAG依据形成双证据链。

无RAG时，Skill必须完成报告内部抽取和可独立复算，并对外部依据输出`basis_status=insufficient`，不得凭模型记忆补标准。
