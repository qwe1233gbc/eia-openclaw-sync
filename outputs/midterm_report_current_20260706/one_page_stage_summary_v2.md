# 阶段性成果与后续计划

## 左栏：阶段性成果

1. 研究对象已收敛到佛山市塑胶行业环评技术审查场景，重点关注涉胶水、涂胶、复合、熟化和 VOCs 治理等项目。
2. 已初步形成标准依据库，整理塑胶行业指南、排放标准、三线一单、产污系数、VOCs 治理等相关依据。
3. 已构建审核技能库雏形，形成 15 个单项审核技能和 1 个总审核技能，用于拆解经验性审查过程。
4. 已形成样本链证据基础，筛选近三年 C292 候选样本链 49 个，本地整理代表性样本链 10 个。
5. 已扩展审核任务数据，当前共 1037 条 QA，其中样本链 QA 95 条，后续可用于筛选人工复核评价题。

## 右栏：后续计划

1. 从 95 条样本链 QA 中筛选 40-60 条高质量题，补充报告页码、标准条款和人工参考答案。
2. 校准标准依据库，完成候选条目去重、版本核查、适用边界和强制性层级标注。
3. 将审核技能与真实专家意见、技术评估意见和样本链案例绑定，形成可复核的技能证据链。
4. 开展 A/B/C/D 知识条件对照实验，比较仅大模型、标准库、技能库及组合条件下的输出差异。
5. 完成论文方法章节和典型案例章节，重点展示“标准依据-审核技能-样本链证据-人工复核”的研究闭环。

## 底部：当前研究边界与风险提示

当前成果属于阶段性数据准备和方法构建成果，已具备小规模方法试点基础，但尚不能直接形成正式有效性结论。后续仍需专家复核、金标答案校准和样本链证据补强。大模型在本课题中仅作为辅助检索、抽取、比对和评价工具，不替代人工审查和行政审批。
