# 当前数据缺失与解决方案

## 1. 总体判断

当前缺的不是“更多材料”，而是把已有材料整理成可追溯、可复核、可评分的数据。

参考 Chen 论文，本课题现阶段应从“材料收集”转向“评价数据准备”。

## 2. 缺失一：完整样本链缺人工确认

### 当前情况

- 已有本地主链精简版 4 个项目。
- 数据库筛出 50 个完整链候选项目。
- 其中 16 个更贴近胶粘、复合膜、包装、印刷、VOCs 场景。

### 问题

数据库完整链只是索引完整，不等于内容真实可用。需要人工打开确认：

- `HPfile` 是受理公告还是公示版报告；
- 报批稿是否为终稿或拟审批稿；
- 评估意见是否包含真实审核问题；
- 批复是否和该项目对应。

### 解决方案

先选 3-5 个项目，不要一次做 50 个。

优先顺序：

1. 彩川合成材料；
2. 艾心日用品；
3. 数据库 16 个重点候选中选择 2-3 个涉胶、复合膜、包装或印刷项目；
4. 米心作为待补链；
5. 智鑫作为半链参考，不进金标。

## 3. 缺失二：修改意见没有变成审核问题

### 当前情况

已有部分评估意见、修改意见、技术评估意见。

### 问题

这些文件还没有被拆成可评价的问题。

### 解决方案

每个完整链项目先拆 5 条审核问题。

每条只保留 5 个字段：

```text
项目名称
审核问题
报告证据
标准依据
参考答案
```

第一版目标：

```text
5 个项目 × 5 题 = 25 道题
```

## 4. 缺失三：标准依据没有和真实问题绑定

### 当前情况

标准依据库已有基础，但条目数量和版本较多。

### 问题

很多标准条目还停留在“资料库”层面，没有说明它能解决哪个真实审核问题。

### 解决方案

先不全量校准。优先校准和真实样本题相关的标准。

优先主题：

- 国民经济行业分类 C2921-C2929；
- 佛山市塑胶指南适用范围；
- 胶水、涂胶、复合、熟化；
- VOCs 收集和治理；
- 活性炭；
- VOCs 总量；
- 危废识别。

每个审核问题只绑定 1-2 条标准依据。

## 5. 缺失四：QA 测试集没有分层

### 当前情况

最新主工作簿已形成 1037 行候选 QA，其中包含原始候选题和样本链增强题；另已整理 95 条样本链 QA，并从中筛选 60 道正式评价候选题。

### 问题

其中既有真实材料来源，也有工作流生成内容。不能直接作为正式测试集。

### 解决方案

分成三类：

| 类型 | 判断标准 | 用途 |
|---|---|---|
| A 类 | 有真实样本链证据 + 人工确认 | 正式评价题 |
| B 类 | 有材料来源但未复核 | 候选题 |
| C 类 | 工作流生成且缺证据绑定 | 任务池素材 |

近期只需要从 60 道正式评价候选题中优先复核 10-15 道样例，并逐步扩展到 40-60 道 verified gold，不需要审核全部 1037 行候选 QA。

## 6. 缺失五：还没有人工评分记录

### 当前情况

已有 A/B/C/D 对照实验设计。

### 问题

没有人工复核后的模型答案评分记录，因此不能形成有效性结论。

### 解决方案

等 20-30 道金标题准备好后，再跑小实验。

评分先用 0-2 分即可：

```text
0 = 错误或无依据
1 = 部分正确
2 = 正确且有证据
```

不建议一开始使用复杂的 100 分制。
