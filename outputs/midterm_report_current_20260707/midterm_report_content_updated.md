## 2. 研究背景一：地方环评审核是复杂的证据判断

页面标题：

```text
地方环评技术审查具有多标准、多证据、多经验特征
```

页面要点：

- 环评报告包含建设内容、原辅材料、生产工艺、产污环节、治理设施、执行标准和环境管理要求；
- 地方塑胶行业还涉及胶水、涂胶、复合、熟化、VOCs 治理、活性炭、危废和总量控制等专业问题；
- 审核依据分散在国家标准、地方指南、技术规范、历史报告、专家意见和批复文件中；
- 新人接手审核工作时，容易依赖有经验人员带教，缺少结构化知识基础。

讲稿：

环评技术审查不是简单地检查报告格式，而是要综合判断项目事实、污染物产生、治理措施和标准适用是否一致。以佛山市塑胶行业为例，很多项目涉及胶水、复合、熟化和 VOCs 治理，审核人员不仅要看报告文本，还要理解地方技术指南、排放标准和历史审核经验。这些知识目前往往分散在不同文件中，因此有必要先把地方标准和审核经验整理成可检索、可追溯的知识基础。

## 3. 研究背景二：大模型可辅助，但必须受证据约束

页面标题：

```text
大模型适合辅助处理文本，但不能脱离标准和证据自由判断
```

页面要点：

- 大模型具备文本理解、信息抽取、问题归纳和表达生成能力；
- Chen 2026 对环境领域大模型应用的启发在于：需要场景建模、结构化数据、工作流设计和专家验证；
- Kumar 2025 对环境数据抽取的启发在于：专业语料筛选、专家标注、问答构造、RAG 检索和外部验证是关键环节；
- 本课题不做微调，而是借鉴“材料结构化 + 检索增强 + 工作流化 + 人工验证”的方法思路。

讲稿：

大模型可以提高材料检索、信息抽取和文本表达效率，但它不能直接判断一个项目是否可以审批。对环评审查来说，模型输出必须受到标准依据、报告证据和人工复核约束。因此，本课题把大模型定位为辅助工具，主要用于检索、抽取、比对和评价，而不是替代审核人员。

## 4. 科学问题与研究目标

页面标题：

研究目标：

- 构建候选审核任务和人工复核金标题；
- 设计 A/B/C/D 知识条件对照实验，评价不同知识输入对大模型输出的影响。

## 6. 总体技术路线

页面标题：

```text
标准依据库 + 审核技能库 + 样本链证据库 + 大模型辅助评价
```

技术路线：

```text
地方指南 / 标准规范 / 报告样本 / 修改意见 / 批复
        -> 标准依据库
        -> 审核技能库
        -> 样本链证据库
        -> 候选审核任务
        -> 人工金标复核
        -> A/B/C/D 知识条件对照实验
        -> 人工评分、错误分析和知识库迭代
```

讲稿：

标准依据库回答“依据是什么”，审核技能库回答“应该怎么审”，样本链证据库回答“真实项目证据在哪里”。大模型在其中承担辅助检索、抽取、比对和表达的作用，最终仍然需要人工复核和专家校准。
