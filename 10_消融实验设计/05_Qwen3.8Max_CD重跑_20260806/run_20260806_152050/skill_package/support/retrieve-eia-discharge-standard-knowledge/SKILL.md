# 环评排放标准知识整理与检索

## 目标

复现工作流 PPT 的“标准收集—结构化整理—报告要素提取—条件检索—返回证据”逻辑。输出候选标准及原文证据，供审核 Skill 或人工判断，不以关键词命中直接宣告合规。

开始前读取 `references/workflow-source.md`。

## A. 构建结构化知识

### 1. 收集正式材料

- 仅以国家、广东省、佛山市、顺德区等有权机关发布的现行标准、公告和正式附件作为法规依据。
- 记录发布单位、标准编号、发布日期、实施日期、废止或替代关系及文件来源。
- 二次汇总、工作流 PPT 和自动生成条目只作为线索。

### 2. 拆分知识条目

以能够独立支持一次标准匹配的最小条款或表格行为单位，至少保留：

```yaml
knowledge_id: ""
来源层级: "国家|广东省|佛山市|顺德区|待确认"
适用地区: []
适用行业: []
标准类型: ""
原料或树脂: []
生产工艺: []
污染物: []
排放形式: "有组织|无组织|厂界|废水排放|其他"
标准名称: ""
标准编号及版本: ""
限值: ""
单位: ""
适用条件: ""
原文位置: ""
原文依据: ""
生效状态: ""
来源文件或链接: ""
```

限值、单位、基准条件和适用范围不得脱离原表。一个条目无法清楚表达多个条件时继续拆分。

### 3. 人工核验条件

扫描识别不清、表头跨页、标准替代关系不明确、来源层级无法确认或自动结构化改变原意时，标记待人工核验，不进入确定性结果。

## B. 检索报告适用标准

### 1. 提取查询条件

从报告提取：

- 项目所在省、市、区；
- 行业和产品；
- 原料、聚合物或树脂；
- 生产工艺和产污环节；
- 污染物；
- 有组织、无组织、厂界或废水等排放形式；
- 报告已采用的标准名称、编号、类别和限值。

缺失条件保持为空并说明，不用常识补齐。

### 2. 分层过滤

按以下顺序检索：

1. 标准在报告编制或审核时点是否有效；
2. 地区和来源层级是否适用；
3. 行业、产品、原料或树脂是否匹配；
4. 工艺和产污环节是否匹配；
5. 污染物与排放形式是否匹配；
6. 限值的单位、表号、级别和附加条件是否一致。

只要关键适用条件冲突，即使关键词相同也不能作为确定匹配。

### 3. 返回候选及证据

返回主候选、备选和排除项，并说明每个结果的命中条件或排除原因。必须包含标准原文位置和原文依据；缺少原文的条目只能标记“待确认”。


## 约束

- 不按文件夹名称自动认定来源层级。
- 不把自动结构化结果当作正式法规。
- 不因标准编号命中而忽略适用地区、行业、工艺和排放形式。
- 本 Skill 返回知识和匹配解释；最终合规结论由相应审核 Skill 或人工作出。
