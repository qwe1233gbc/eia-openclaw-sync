# 环保投资审核

## 1. 输入

```json
{
  "question_id": "",
  "question": "",
  "report_context": ""
}
```

本Skill仅依赖报告事实，不需要法规知识库。

## 2. 证据字段

- 总投资；
- 环保投资；
- 报告填报的环保投资占比；
- 环保工程各分项名称、金额和单位；
- 不同章节或表格中的重复金额；
- 报告显示精度。

## 3. 审核流程

1. 提取所有投资金额及证据位置。
2. 统一元、万元等单位。
3. 计算：
   - `环保工程分项合计 = Σ各分项金额`
   - `环保投资占比 = 环保投资 ÷ 总投资 × 100%`
4. 比较：
   - 分项合计与环保投资；
   - 复算占比与填报占比；
   - 基本情况表与环保工程表；
   - 是否存在重复项、漏项或单位冲突。
5. 保留原始值、计算值、差额和舍入后的显示值。

## 4. 容差

默认仅允许显示精度造成的舍入差异。报告没有明确精度时：

- 金额差额必须为0，或明确说明差额来源；
- 百分比可按报告小数位数进行四舍五入比较；
- 不得用任意5%或10%误差掩盖计算错误。

## 5. 结论

- `正确`：分项合计、环保投资和占比均一致；
- `存在问题`：分项合计不等、比例计算错误、单位冲突、重复或漏项；
- `待人工复核`：关键金额缺失或表内外数值冲突且无法确定采用值。

输出中`external_validation_result.status=not_required`。
