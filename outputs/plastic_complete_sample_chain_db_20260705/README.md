## 5. 使用建议

1. 先不要批量下载全部 50 个项目的原始文件，优先从 16 个重点候选中选 3-5 个做人工复核。
2. 每个项目按 ile_index.csv 中的四类索引下载或定位文件：受理/公示、报批稿/终稿、评估/修改意见、批复。
3. 人工确认后，将项目标为：完整链、待补链、半链、排除样本。
4. 完整链项目再进入后续三张研究表：项目事实抽取表、修改意见-报告证据表、批复要求-报告依据表。
5. 该目录只保存数据库索引和清单，不保存原始 PDF/DOC/DOCX 文件。

## 6. 当前结论

数据库中可筛出 50 个高可信塑胶行业新建项目完整链候选，其中 16 个与当前课题关注的胶粘、复合膜、包装、印刷、VOCs 场景更相关。后续应优先对这些项目进行人工复核，而不是直接把 50 个候选全部作为金标样本。
