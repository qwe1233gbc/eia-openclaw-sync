# PDF 与表格清洗增强 md 等价性核查摘要

## 方法

- 使用 pdfplumber/pdfminer 从原始 PDF 提取文本层。
- 同时使用 line-based 与 text-based table extraction 抽取 PDF 表格。
- 与对应项目的表格清洗增强 md 段落进行行级比对。
- 判定关注审核等价：字段、数值、单位、对象关系是否保留；不判断 PDF 视觉版式是否完全复刻。
