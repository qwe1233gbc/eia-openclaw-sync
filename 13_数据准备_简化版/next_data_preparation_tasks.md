# 下一步数据准备任务

## 目标

用最少字段、最少项目，先做出一版可用于中期汇报和后续实验的小型高质量数据集。

## 第一步：确定 3-5 个核心项目

建议项目池：

| 项目 | 当前状态 | 是否优先 |
|---|---|---|
| 彩川合成材料 | 本地较完整链 | 是 |
| 艾心日用品 | 本地较完整链 | 是 |
| 米心塑业 | 缺受理公告/公示版 | 可作为待补链 |
| 智鑫塑胶 | 半链 | 只作参考 |
| 数据库 16 个重点候选项目 | 待人工确认 | 选 2-3 个 |

执行要求：

- 每个项目只看四类材料；
- 不处理无关附件；
- 缺失就写缺失说明。

## 第二步：每个项目整理四类文件

目录结构固定为：

```text
01_受理公告或公示版
02_报批稿或终稿
03_修改意见或评估意见
04_批复
```

判断结果只分：

```text
完整链
待补链
半链
排除
```

## 第三步：每个完整项目拆 5 道题

每道题只填 5 个字段：

```text
项目名称
审核问题
报告证据
标准依据
参考答案
```

题型优先选择：

- 行业分类是否准确；
- 是否适用佛山市塑胶行业指南；
- 是否识别胶水、涂胶、复合、熟化等工艺；
- VOCs 收集和治理是否合理；
- 修改意见是否在终稿中回应；
- 批复要求是否能在报告中找到依据。

## 第四步：从 60 道正式评价候选题中复核金标题

不要全量处理。

筛选标准：

- 能绑定到核心项目；
- 能找到报告证据；
- 能找到标准依据；
- 人工能判断对错。

第一版先复核 10-15 道样例，后续扩展到 40-60 道 verified gold。

## 第五步：准备小规模实验

数据准备完成后再做 A/B/C/D：

| 组别 | 输入条件 |
|---|---|
| A | 只给问题和报告片段 |
| B | 加标准依据 |
| C | 加审核技能步骤 |
| D | 加标准依据 + 技能步骤 + 样本链证据 |

评价先用 0-2 分：

```text
0 = 错误或无依据
1 = 部分正确
2 = 正确且有证据
```

## 一周内可完成的最小任务

```text
1. 人工确认彩川、艾心两条完整链；
2. 从彩川拆 5 道审核题；
3. 从艾心拆 5 道审核题；
4. 从数据库 16 个候选中选择 2 个下载核查；
5. 形成第一版 10-20 道人工复核题。
```

完成这一步后，就可以说：本课题已从材料整理进入“证据绑定型评价数据构建”阶段。
