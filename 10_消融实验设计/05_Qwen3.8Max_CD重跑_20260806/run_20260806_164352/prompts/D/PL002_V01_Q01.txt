# 国民经济行业分类人工审核方法

## 目录

1. 判断对象
2. 证据优先级
3. 七步审核法
4. 候选小类对照表
5. 主要活动判定
6. 结论门槛与输出映射
7. 常见误判
8. 官方依据

## 1. 判断对象

行业 = 从事相同性质经济活动的单位集合。行业分类判断的是“单位实际从事的经济活动”，不是企业名称、主管部门或营业执照文字。

主要活动 = 一个单位对外从事两种以上经济活动时，占单位增加值份额最大的一种活动；增加值无法确定时，可依据销售收入、营业收入或从业人员确定。

人工审核需要分别回答三个问题：

1. 项目实际有哪些可独立对外提供的经济活动？
2. 每条活动最符合哪个四位小类？
3. 哪条是主要活动，报告填报是否完整、准确？

## 2. 证据优先级

| 优先级 | 证据 | 审核作用 |
|---|---|---|
| A | 最终对外产品、产品用途、核心工艺 | 决定经济活动性质 |
| A | 现行官方小类定义、包括项、不包括项 | 决定类别边界 |
| A | 增加值；替代为销售/营业收入、从业人员 | 决定主要活动 |
| B | 主要原料/基材、设备、产能 | 支撑或反驳活动描述 |
| B | 产排污环节、产污系数所属行业 | 交叉验证，不单独定类 |
| C | 项目名称、经营范围、备案、报告自报代码 | 仅作检索线索 |

最终产品是“完成本项目生产后对外销售或交付的产品”，不是中间物料、边角料或设备内部形成物。核心工艺是“决定最终产品材料形态、功能或用途的关键加工”，不是包装、搬运等末端动作。

## 3. 七步审核法

### 第一步：抄录填报值

同时抄录门类字母、四位代码和类别名称。代码与名称本身不一致时，先标记形式错误，再继续判断实际活动。

### 第二步：提取五类事实

从基本情况、产品表、原辅材料表、设备表和工艺说明中提取：

- 最终产品是什么；是否对外销售；规格和用途是什么。
- 主要原料是树脂颗粒、原纸、外购薄膜、半成品还是其他基材。
- 是否发生聚合、挤出、注塑、吹膜、涂布、复合、熟化、印刷、切割等核心变化。
- 每条产品线的产能、销售/营业收入、增加值和人员配置。
- 产品、原料、设备和工艺是否前后一致。

### 第三步：写经济活动句

使用固定句式压缩事实：

> 使用【主要原料/基材】，通过【核心工序】，生产用于【用途】的【最终对外产品】。

若一句话中出现两个互不依赖的最终产品，拆成两条活动。若某工序只为本单位主产品服务且不对外提供，标为辅助活动。

### 第四步：检索候选小类

按以下顺序检索：

1. 最终产品准确名称。
2. 产品同义词、材料名称和主要用途。
3. 核心工艺名称。
4. 可能的上位中类和近邻小类。

必须读取小类“指……”定义及注释中的“包括”“不包括”，不能只查代码表名称。由小类向上检查中类、大类、门类，防止名称相似但经济活动性质不同。

### 第五步：做近邻排除

每条活动至少保留一个主要候选和一个近邻候选。逐项比较最终产品、基材、核心工艺、用途、包括项、不包括项。证据不能排除近邻时，对外结论统一写“需复核”，并写明缺少的证据。

### 第六步：确定主要活动

多活动单位按以下顺序：

`增加值份额 → 销售/营业收入份额 → 从业人员份额`

只比较同一报告期、同一统计口径的数据。吨、万个、万米等不同产能单位不能直接比较；同为“万米”也不能自动代表价值份额。环评报告缺少财务数据时，可判断各活动对应小类，但不能擅自确定唯一主要行业。

### 第七步：与报告比对

检查：代码与名称是否成对、每个独立活动是否覆盖、是否错误列入辅助活动、是否说明主要与次要关系、引用版本是否现行。证据、候选和边界用于内部审核记录，对外按 Skill 规定的“生产活动摘要＋判定结论＋具体分析”输出。

## 4. 候选小类对照表

| 比对维度 | 要回答的问题 | 可接受证据 |
|---|---|---|
| 最终产品 | 项目最后对外交付什么？ | 产品表、合同/用途说明、工艺终点 |
| 主要原料 | 从什么材料开始加工？ | 原辅材料表、物料平衡 |
| 核心工艺 | 哪一步决定产品材料形态或功能？ | 流程图、设备参数、工艺说明 |
| 产品用途 | 产品进入哪个使用场景？ | 产品备注、客户用途、技术规格 |
| 包括项 | 官方注释是否明确列入？ | 现行分类注释原文 |
| 不包括项 | 官方注释是否明确转列其他小类？ | 现行分类注释原文及转列代码 |
| 主要活动 | 哪项增加值份额最高？ | 增加值或允许的替代指标 |

推荐记录法：`命中=1，冲突=-1，证据缺失=?`。该符号只帮助检查，不得机械加总成分类结论；“不包括”命中或最终产品性质冲突通常具有否决作用。

## 5. 主要活动判定

区分三种情形：

1. 单一产品、单一经济活动：直接按该活动定类。
2. 多产品但属于同一小类：仍归同一小类，不必为每个产品列代码。
3. 多产品且分属不同小类：分别判断活动小类，再确定主要活动；环评中可说明次要活动，但单位行业归属以主要活动为准。

内部维修、自用模具、自用包装、自建环保设施等不对外提供的活动属于辅助活动。若模具或印刷品同时对外销售，则重新作为独立活动审核。

## 6. 结论门槛与输出映射

| 内部审核状态 | 对外结论 | 必须满足的条件或写法 |
|---|---|---|
| 一致且证据充分 | 正确 | 最终产品、核心工艺、用途、官方注释和主要活动证据齐全；代码名称一致；近邻已排除 |
| 方向基本成立但证据不完整 | 需复核 | 写明缺少用途、主要活动指标、边界说明或证据位置中的哪一项 |
| 识别类别与填报类别不同 | 需复核 | 同时写出识别类别、填报类别和具体差异，禁止只写“需复核确认” |
| 无法判断 | 需复核 | 写明缺少最终产品、核心工艺、用途、官方依据或主要活动证据 |

## 7. 常见误判

- 看到“塑料粒”就判塑料制品业：原料不等于最终产品。
- 看到“印刷机”就另列印刷业：自用标识印刷可能只是主产品的辅助工序。
- 用产品长度、吨数直接判断主行业：不同产品价值和加工增值不可比。
- 把环评分类管理名录条目当成国民经济行业代码：两套分类目的和层级不同。
- 只查小类名称，不查注释：边界往往写在“包括/不包括”中。
- 一开始就用尾数为 9 的“其他”类：应先排除更具体小类。
- 用产污系数反推行业：产污系数只能验证，不能覆盖最终产品与工艺证据。
- 报告写了两个代码就默认都正确：需先证明存在两条独立经济活动，并说明主要与次要关系。

## 8. 官方依据

先使用 Skill 内置的 `2017国民经济行业分类注释_按第1号修改单修订.xlsx` 及检索脚本核对四位小类，再核实现行版本。优先使用：

- 国家统计局《国民经济行业分类》（按第 1 号修改单修订）：https://www.stats.gov.cn/sj/tjbz/gmjjhyfl/
- 国家统计局《2017国民经济行业分类注释》（按第 1 号修改单修订）：https://www.stats.gov.cn/sj/tjbz/gmjjhyfl/202302/t20230213_1902780.html
- 国家统计局“如何查询某一单位所属的国民经济行业分类代码”使用指导：https://www.stats.gov.cn/hd/cjwtjd/202302/t20230207_1902279.html
- 疑难边界优先检索国家统计局“国民经济行业分类”咨询公开；个案答复作为解释性参考，仍需核对项目事实是否一致。

审核记录写明标准名称、版本/修改单、官方页面、访问日期和具体小类注释，禁止仅写“依据国民经济行业分类”。

# 国民经济行业分类审核

## 1. Skill定位

本Skill是现有行业分类Skill的整理版，不新建重复条目。

保留：

- 产品、原料、工艺和用途证据抽取；
- 多产品链分析；
- 行业分类注释检索；
- 填报类别与独立判断比较；
- 结构化证据链。

删除：

- 测试项目专属案例；
- PL001固定事实和固定结论；
- 任何人工金标。

## 2. 输入

```json
{
  "question_id": "",
  "question": "",
  "report_context": "",
  "report_date": "",
  "reference_mode": "embedded_verified_classification"
}
```

报告上下文不得包含Word批注、修订痕迹和人工修改意见。

## 3. 必须抽取的证据

- E1：报告填报的行业代码和名称；
- E2：最终产品、用途、产能和备注；
- E3：主要原辅材料；
- E4：决定产品性质的核心工艺；
- E5：不同章节中的行业、产品和工艺表述。

不强制要求增加值、营业收入或从业人员证据。多产品属于不同小类时，可分别列出，不得因缺少主要活动权重而否定所有分类。

## 4. 审核流程

1. 建立每条生产活动：
   `主要原料 → 核心工艺 → 最终产品 → 产品用途`。
2. 多产品分别建立活动链，不将内部包装、维修、自用模具等辅助活动单独定类。
3. 使用内置检索脚本查询分类注释：
   - 按代码：`python scripts/search_industry_classification.py --code C2929`
   - 按关键词：`python scripts/search_industry_classification.py --keyword 塑料薄膜`
4. 核对定义、包括项、不包括项和近邻小类。
5. 与报告填报类别逐项比较。
6. 只有关键产品、工艺或分类注释无法取得时，才判“待人工复核”。

## 5. 结论规则

- `正确`：产品—工艺—用途与正式分类注释相符，且与报告填报一致；
- `存在问题`：填报代码名称错配、遗漏独立产品线或与分类定义不符；
- `待人工复核`：报告关键事实缺失、分类文件版本不明或近邻小类无法排除。

不得因为没有RAG而直接拒答；本Skill自身已包含经确认的分类注释参考。

## 6. 输出

使用`../../shared/output_schema.json`。

`external_validation_result.status`填写：

- 已使用内置且版本确认的正式分类注释：`verified`；
- 分类注释版本尚未确认：`insufficient_reference`。

## 7. 禁止事项

- 禁止读取或恢复`liangzheng-case.md`；
- 禁止硬编码PL001、Question ID或固定答案；
- 禁止仅按原料关键词直接定类；
- 禁止把建设项目环境影响评价分类管理名录类别当作国民经济行业类别。
